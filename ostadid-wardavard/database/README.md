# زیرساخت داده پروژه اساتید وردآورد

## دو شیوه نگهداری داده

### ۱) پایگاه داده محلی مرورگر
صفحه `admin/database.html` بدون نیاز به سرور، داده‌ها را در IndexedDB همان مرورگر نگهداری می‌کند. داده‌ها بین دستگاه‌ها و مرورگرهای مختلف همگام نمی‌شوند. از بخش «دریافت نسخه پشتیبان» برای خروجی JSON و از «بازیابی نسخه پشتیبان» برای ورود داده استفاده کنید.

### ۲) پایگاه داده هاست
برای استفاده مشترک اعضا و مدیران، فایل‌های PHP و MySQL روی هاست قرار می‌گیرند:
1. دیتابیس و کاربر MySQL را در کنترل‌پنل هاست بسازید.
2. فایل `schema.mysql.sql` را در همان دیتابیس اجرا کنید.
3. `config.example.php` را به `config.php` تغییر نام دهید و مشخصات دیتابیس و یک کلید تصادفی طولانی را در آن قرار دهید.
4. مقدار `allowed_origin` را فقط روی دامنه واقعی سایت تنظیم کنید؛ از `*` استفاده نکنید.
5. پوشه `database` را در مسیر سایت آپلود کنید و نشانی `api.php` را در بخش «پایگاه داده هاست» پنل مدیریت وارد کنید.
6. پوشه مدیریت را با قابلیت Password Protect هاست یا محدودیت دسترسی معادل محافظت کنید.

برای ساخت دیتابیس محلی سمت سرور نیز می‌توان در `config.php` مقدار `driver` را `sqlite` قرار داد و فایل `schema.sqlite.sql` را روی فایل معرفی‌شده در `sqlite_path` اجرا کرد. این حالت به PHP با افزونه PDO_SQLite نیاز دارد.

## جدول‌ها
- `requests`: درخواست‌ها و نقل‌وانتقال‌ها، کد رهگیری، وضعیت و یادداشت کارشناس.
- `monthly_reports`: گزارش ماهانه، درصد تجمیعی، اقدامات و گالری تصاویر.
- `announcements`: خبرها و اطلاعیه‌ها.

## مسیرها
- مدیریت داده‌ها: `admin/database.html`
- API: `database/api.php`
- ساختار MySQL: `database/schema.mysql.sql`
- ساختار SQLite: `database/schema.sqlite.sql`

## نکته امنیتی
فایل واقعی `config.php`، رمز دیتابیس و کلید API را در GitHub قرار ندهید. کلید API در درخواست مرورگر قابل مشاهده است؛ بنابراین پنل مدیریت باید حتماً با احراز هویت هاست محافظت شود. برای استقرار عملیاتی با چند نقش کاربری، احراز هویت سمت سرور و ثبت رخدادهای مدیریتی باید فعال شود.
