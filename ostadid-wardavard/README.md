# وب‌سایت پروژه اساتید وردآورد

این وب‌سایت به‌صورت مستقل در پوشه `ostadid-wardavard` نگهداری می‌شود.

## صفحات عمومی
- `index.html` صفحه اصلی
- `pages/project.html` معرفی پروژه
- `pages/location.html` موقعیت و دسترسی
- `pages/progress.html` گزارش‌های ماهانه و پیشرفت تجمیعی
- `pages/news.html` اخبار و اطلاعیه‌ها
- `pages/gallery.html` گالری تصاویر
- `pages/contact.html` ارتباط با پروژه
- `pages/systems.html` مرکز سامانه‌ها
- `pages/transfer.html` خدمات نقل‌وانتقال
- `pages/inquiry.html` استعلام و پیگیری
- `pages/managers.html` درگاه مدیران

## هویت بصری
- ساختار منو، اندازه‌ها، فاصله‌ها، زیرمنو و رفتار موبایل از پوسته اصلی وب‌سایت آفتاب رامسر منتقل شده است.
- عنوان نوشتاری «اساتید وردآورد» با فونت محلی Shekasteh ساخته شده است.
- فونت‌های Vazirmatn و Shekasteh در `assets/fonts` نگهداری می‌شوند.
- هدر و فوتر از الگوی رنگی و بافت محلی استفاده می‌کنند؛ هیچ فونت یا تصویر خارجی برای اجزای پوسته لازم نیست.

## تصاویر
تصاویر محلی در `assets/images` ذخیره می‌شوند. برای دریافت یا به‌روزرسانی تصاویر:
- اسکریپت: `scripts/download_wardavard_images.py`
- گردش‌کار GitHub Actions: `.github/workflows/download-wardavard-images.yml`

شش تصویر فعلی از منابع تصویری Unsplash دریافت شده‌اند و برای نمایش نمونه مراحل اجرا و معماری به کار می‌روند؛ این تصاویر مستند واقعی کارگاه پروژه نیستند. تصاویر واقعی پروژه باید با مستندات تاریخ‌دار کارگاه جایگزین شوند. اطلاعات منبع تصاویر در `assets/images/sources.json` ثبت شده است.

## گزارش پیشرفت
صفحه گزارش پیشرفت دارای فیلتر سال و ماه شمسی، گزارش‌های دوره‌ای، اقدامات، رویدادها، گفت‌وگوهای فنی، گالری و نمودار پیشرفت تجمیعی است. برنامه زمانی سه‌ساله در صفحه نمایش داده می‌شود. درصد و گزارش‌های فعلی، محتوای اولیه قابل ویرایش‌اند و باید در زمان دریافت گزارش‌های تأییدشده فنی به‌روزرسانی شوند.

## پایگاه داده
- پنل مدیریت: `admin/database.html`
- مدیریت محلی مرورگر با IndexedDB و امکان نسخه پشتیبان JSON
- API سمت سرور: `database/api.php`
- ساختار MySQL هاست: `database/schema.mysql.sql`
- ساختار SQLite: `database/schema.sqlite.sql`
- راهنمای نصب: `database/README.md`

برای فعال‌سازی پایگاه داده مشترک هاست، لازم است مشخصات دیتابیس در فایل خصوصی `database/config.php` تنظیم شود. این فایل و کلید API نباید وارد مخزن عمومی شوند. پنل مدیریت نیز باید با رمز عبور هاست محافظت شود.

## حریم اطلاعات
نام عمومی سایت «پروژه اساتید وردآورد» است. نام نهاد/تعاونی و شناسه‌های حقوقی، ثبتی و شهرداری در محتوای عمومی نمایش داده نمی‌شوند.
