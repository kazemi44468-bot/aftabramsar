# وب‌سایت پروژه اساتید وردآورد

این وب‌سایت به‌صورت مستقل در پوشه `ostadid-wardavard` نگهداری می‌شود.

## صفحات
- `index.html` صفحه اصلی
- `pages/project.html` معرفی و شناسنامه عمومی پروژه
- `pages/location.html` موقعیت و نقشه مختصات
- `pages/gallery.html` گالری تصاویر نمونه معماری
- `pages/contact.html` ارتباط با پروژه
- `pages/systems.html` مرکز سامانه‌ها
- `pages/transfer.html` سامانه نقل‌وانتقال
- `pages/inquiry.html` سامانه استعلام
- `pages/managers.html` سامانه مدیران

## فونت‌ها
فونت‌های محلی پروژه در `assets/fonts` قرار دارند. فونت Vazirmatn برای متن عمومی و فونت Shekasteh برای عنوان‌ها و عناصر تزئینی استفاده می‌شود. مسیرها در `assets/css/site.css` به‌صورت نسبی و محلی تعریف شده‌اند.

## موقعیت
مختصات ارائه‌شده برای پروژه:
`35.7434720763264, 51.143197592243396`

نقشه در صفحه اصلی و صفحه موقعیت از OpenStreetMap نمایش داده می‌شود.

## تصاویر
گالری از تصاویر نمونه معماری مسکونی و محوطه‌سازی منابع اینترنتی استفاده می‌کند. این تصاویر نمونه الهام‌بخش هستند و عکس واقعی زمین یا ساختمان پروژه محسوب نمی‌شوند. در نسخه فعلی تصاویر به‌صورت مستقیم از نشانی منبع بارگذاری می‌شوند و هنوز نسخه محلی آن‌ها در مخزن ذخیره نشده است.

## وضعیت سامانه‌ها
صفحات سامانه‌ها در حال حاضر رابط کاربری اولیه هستند. برای ثبت و بازیابی واقعی اطلاعات، احراز هویت مدیران، ذخیره مدارک و پیگیری پرونده‌ها باید سرویس سمت سرور و پایگاه داده امن متصل شود.

## حریم اطلاعات
نام عمومی سایت «پروژه اساتید وردآورد» است. نام نهاد/تعاونی و شناسه‌های حقوقی، ثبتی و شهرداری در محتوای عمومی نمایش داده نمی‌شوند.
