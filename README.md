# آفتاب رامسر
وب‌سایت استاتیک فارسی، راست‌چین و واکنش‌گرا.

## تصاویر
تصاویر واقعی از Wikimedia Commons در پوشه `assets/images/` ذخیره می‌شوند. فایل `assets/images/sources.json` برای هر تصویر نام فایل، صفحه منبع، پدیدآورنده و مجوز را نگه می‌دارد. شرایط مجوز و انتساب هر عکس را رعایت کنید.

گردآوری تصاویر با GitHub Actions انجام می‌شود. گردش‌کار **Collect Ramsar photos** تصاویر موجود را به مسیر جدید منتقل می‌کند و فهرست را به‌روزرسانی می‌کند.

## فونت‌ها
فونت‌های محلی در `assets/fonts/` قرار دارند. سایت از وزن‌های مختلف Vazirmatn برای متن و از Shekasteh برای تیتر اصلی استفاده می‌کند.
