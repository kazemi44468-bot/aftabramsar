# آفتاب رامسر
وب‌سایت استاتیک فارسی، راست‌چین و واکنش‌گرا.

## تصاویر
تصاویر واقعی از Wikimedia Commons در پوشه `images/` ذخیره می‌شوند. فایل `images/sources.json` برای هر تصویر نام فایل، صفحه منبع، پدیدآورنده و مجوز را نگه می‌دارد. شرایط مجوز و انتساب هر عکس را رعایت کنید.

گردآوری تصاویر با GitHub Actions انجام می‌شود. پس از ثبت فایل گردش‌کار، به بخش **Actions** بروید و گردش‌کار **Collect Ramsar photos** را در صورت نیاز دستی اجرا کنید. در صورت موفقیت، تصاویر به پوشه `images/` commit می‌شوند.

## لوگو و فونت
لوگوی رسمی را با نام `logoaftab.png` در ریشه مخزن قرار دهید. فونت محلی اختیاری: `assets/fonts/Vazirmatn.woff2`.
